Giới thiệu về bài thực hành

Trang web này tổng hợp chuỗi 03 bài thực hành JavaScript nhằm vận dụng ngôn ngữ để xây dựng và phát triển các tính năng tương tác trực quan trên website thương mại điện tử.

Danh sách các bài Lab

Bài Lab Nội dung chính Yêu cầu
Lab 08 JavaScript 1: Language Foundations (Biến, hàm, Array, Object...)[cite: 1, 4] Truy cập Lab 08
Lab 09 JavaScript 2: DOM and Events (Truy xuất DOM, xử lý sự kiện, Form)[cite: 1, 4] Truy cập Lab 09
Lab 10 JavaScript 3: jQuery (Selectors, Animation, GET Requests)[cite: 1, 4] Truy cập Lab 10

Kiến thức và kỹ năng đã học

  • Lab 08 - JavaScript 1: Language Foundations: Làm quen cú pháp JavaScript, sử dụng biến, hàm, cấu trúc dữ liệu String, Date, Array, Object và thao tác với Browser Console[cite: 4].
  • Lab 09 - JavaScript 2: DOM and Events: Truy xuất phần tử qua DOM, thay đổi nội dung/thuộc tính, xử lý sự kiện người dùng (click, hover) và kiểm tra dữ liệu Form[cite: 4].
  • Lab 10 - JavaScript 3: jQuery: Sử dụng thư viện jQuery, viết bộ chọn (Selectors), thao tác DOM nhanh gọn, tạo hiệu ứng Animation và gọi GET Requests[cite: 4].

Tự đánh giá sau khi hoàn thành

Thông qua chuỗi bài thực hành này, tôi đã nắm vững các kỹ thuật lập trình JavaScript từ cơ bản đến nâng cao, biết cách thao tác linh hoạt với DOM và ứng dụng thư viện jQuery để tăng tính tương tác cho giao diện. Kiến thức này rất thiết thực trong phát triển thương mại điện tử, giúp tôi tự tin xây dựng các chức năng như kiểm tra dữ liệu biểu mẫu đăng ký, quản lý giỏ hàng động, cập nhật nội dung sản phẩm và tạo hiệu ứng trực quan trên website bán hàng[cite: 5]. Tuy nhiên, tôi vẫn cần tiếp tục rèn luyện thêm về tư duy tối ưu mã nguồn và xử lý bất đồng bộ trong các dự án thực tế sắp tới.
